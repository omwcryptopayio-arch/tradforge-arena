# DIFFICULTY — Standard / High / Premium

Difficulté = **plus de bruit + plus d'autonomie**, pas « plus de données ».

## Standard (2★)
- Mécanique : MCQ pur sur replay scénarisé.
- Cards : aucune (guidage naturel).
- Chart : 60-90 bougies.

## High (4★)
- Mécanique : Macro Decision Workspace (recherche libre → décision directionnelle).
- Cards : 4-6, mix pertinent + 2-3 distracteurs.
- Affichage cards : **guidé** — résumé texte, information cadrée, compréhension facilitée.
- Mesure clé : Research Efficiency.
- Chart : 90-120 bougies.

## Premium (5★)
- Mécanique : Reasoning capturé + Indice de Cohérence + Timer 2:30 dégressif.
- Cards : 6-9, **aucune** indication de pertinence.
- Affichage cards : **analyste** — dashboards, line charts, séries historiques,
  statistiques, calendriers, tableaux, courbes, multi-timeframe. Reproduit un desk macro.
- Mesures : Research Efficiency + Coherence Index (non pénalisant) + temps/dépassement.
- Chart : 120-160 bougies, 2 délimiteurs, HUD pips/direction au reveal.

## Sélection des cards par relevance (invisible)
- Standard : cards `relevance` très élevée uniquement.
- High : principales + quelques secondaires.
- Premium : toutes.
`ESSENTIAL_THRESHOLD = 72` (essentiel si `relevance >= 72`).
